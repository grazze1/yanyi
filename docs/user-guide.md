# 研译用户手册

## 安装 Edge / Chrome 扩展

开发构建分别位于 `apps/edge-extension/.output/edge-mv3` 与 `chrome-mv3`。在浏览器扩展管理页开启开发者模式并“加载解压缩的扩展”。随后运行 `scripts/Install-NativeHost.ps1 -Browser Edge` 或 `-Browser Chrome`；诊断页应显示已注册。

正式安装使用 `target/release/bundle/nsis/研译_0.1.0_x64-setup.exe`。安装钩子会复制版本化只读 Native Host 并为两个浏览器注册独立 manifest。

## 配置 API

在桌面端“模型与 API”输入 HTTPS Base URL、API Key、可选 HTTPS 代理和超时/并发/重试。Key 提交后立即 DPAPI 加密，界面只回显掩码。连接测试会产生一条极小真实请求；命令行等价入口为 `scripts/Test-DeepSeekConnection.ps1 -ConfirmBilling`。

## 翻译网页

打开 popup，确认本地服务已连接，选择显示模式、领域和任务预设后开始翻译。页面工具条可切换模式、暂停、继续、取消和恢复原文。长页只扫描受预算约束的正文；已完成分段会缓存并在刷新后复用。

## 术语库

桌面端可新增固定译法、永不翻译、多义词和附原文策略。页面/网站/工作区/领域/全局构成作用域优先级。候选术语必须人工确认。JSON 支持合并、覆盖或跳过导入；每次最多 5000 条、10 MB。

## 解释、追问和笔记

右键选区可翻译、解释、追问、加入术语库、设为永不翻译或保存笔记。侧边栏传递选区、相邻上下文、标题和 URL；模型不能直接访问 DOM。回答按会话保存到本地数据库。

## 工作区与记忆

工作区隔离领域、文档、术语、会话和记忆。自动内容只进入候选列表；只有用户确认的事实/偏好和明确保存的笔记能成为长期记忆。

## PDF 阅读

Options 中打开 PDF 阅读器，可选择本地文件或显式授予站点访问权限后打开 URL。支持文本层、导航、缩放、搜索、当前页/章节翻译、双语与阅读位置。无文本层时只显示 OCR 未配置状态，不会上传页面图片。

## 数据与隐私

桌面端可备份 SQLite、验证并安排导入、清缓存、导出脱敏诊断。导入在重启替换前创建备份。数据默认位于 `%LOCALAPPDATA%\Yanyi`。

## 故障排查

- “Host not found”：在诊断页修复注册，或运行 `Install-NativeHost.ps1`，然后重启浏览器。
- API 401/402/429：分别检查密钥、余额、频率；程序不会自动切换供应商。
- 页面不可翻译：浏览器内部页、商店页和受保护 PDF 不允许内容脚本注入。
- PDF URL 失败：确认已授予该来源权限，且文件小于 50 MB、无跨站重定向。

## 卸载

常规卸载清除注册与程序文件并保留数据库。脚本方式：`Uninstall-NativeHost.ps1 -Browser All`。完全删除必须显式增加 `-DeleteUserData`，此操作不可恢复。
